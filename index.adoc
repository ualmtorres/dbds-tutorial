== Descripción del curso

Este curso proporciona una introducción a las bases de datos relacionales y al lenguaje SQL, con un enfoque en su aplicación en la ciencia de datos. Los estudiantes aprenderán a diseñar, crear y gestionar bases de datos, así como a realizar consultas utilizando SQL para extraer y analizar datos. Se cubrirán temas como las relaciones entre tablas, las funciones de agregación y las subconsultas. Además, se explorarán técnicas avanzadas de SQL, como las funciones de ventana. El curso también incluirá prácticas utilizando Jupyter Notebooks para ejecutar consultas SQL y analizar los resultados, proporcionando a los estudiantes una experiencia práctica en el manejo de bases de datos en un entorno de Ciencia de datos.
